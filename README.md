# Digital Logic Gate Simulator

An interactive browser-based digital electronics project for exploring how common logic gates process binary inputs.

## What it demonstrates

- AND, OR, NOT, NAND, NOR, XOR, and XNOR gates
- Live A/B input toggles with instant output updates
- Gate expressions and plain-English explanations
- Generated truth tables with the active row highlighted
- A responsive, accessible interface that works without a framework or build step

## Run locally

Clone the repository and open index.html in any modern browser:

    git clone https://github.com/Anumaan1/Digital-Logic-Gate-Simulator.git
    cd Digital-Logic-Gate-Simulator
    # Open index.html in your browser

No installation, server, or API key is required.

## Project structure

- index.html — application layout and accessible controls
- styles.css — responsive visual design
- script.js — gate logic, circuit display, and truth-table rendering

## Logic reference

| Gate | Output |
| --- | --- |
| AND | 1 only when both inputs are 1 |
| OR | 1 when at least one input is 1 |
| NOT | Inverts the input |
| NAND | Inverted AND |
| NOR | Inverted OR |
| XOR | 1 when the inputs are different |
| XNOR | 1 when the inputs are the same |

## Learning goals

This project is useful for practicing Boolean algebra, truth tables, binary state, and the relationship between a circuit's inputs and its output.
